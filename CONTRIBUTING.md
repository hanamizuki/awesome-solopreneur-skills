# Contributing

Thanks for your interest in contributing! This repo welcomes both original skills and links to community skills.

## Submitting a Community Skill (Link)

If you know a great skill that solopreneurs would find useful:

1. Open an issue or PR
2. Include: skill name, link, platform (Claude Code / OpenClaw / other), and which category it belongs to (Development, Marketing, Content, Design, Operations)
3. Add a one-line description of what it does

## Submitting an Original Skill (Source Code)

If you want to contribute a skill with source code:

1. Fork this repo
2. Add your skill under `skills/claude-code/your-skill-name/` or `skills/openclaw/your-skill-name/`
3. Include a `README.md` in the skill directory explaining what it does and how to use it
4. Open a PR with a description of the skill and which category it fits

## Categories

- **Development** — Building, shipping, and maintaining your product
- **Marketing** — SEO, ads, analytics, sales, pricing, landing pages
- **Content** — Writing, social media, replies, scheduling, visuals
- **Design** — UI/UX, branding, visual design
- **Operations** — Automation, scheduling, customer support, finance, project management

## Quality Bar

- Skills should solve a real solopreneur problem
- Include clear usage instructions
- No API keys or secrets in source code
